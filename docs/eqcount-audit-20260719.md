## 方法

**我方（OUR）计数** — 由两个独立 agent 核算并交叉验证：
- 方法 1（源标签）：每章 `chapters/pX-chNN-*.md` 中 `:label: eq-p` 行数。
- 方法 2（渲染 id）：`myst build` 后，在 `_build/site/content/<slug>.json` 中数 `html_id:"eq-p…"` 的**已定义方程节点**（排除 `crossReference` 链接节点）。
- 两者逐章一致（1499 = 1499），构建 0 warning / 0 error / 0 undefined / 0 duplicate。

**PDF 方（GROUND TRUTH）计数** — 由独立 agent 从 MinerU `layout.json`（直接由源 PDF 解析得到，网络无关）提取：
- 取 `interline_equation` 块内的 `\tag{c.k}`，右对齐判定（x0 > 0.65×页宽）。
- 解析章号 c、公式号 k；子公式 `(c.k a)` 折叠为 k。
- 按章合并（p1/p2 各有 2 个 PDF，已合并）。
